## Build with Local Franca

Use the `build_with_local_franca.sh` script to build the tools using a locally generated version of Franca.

### Prerequisites
* **Java 8** is required to run the build process.

### Script Usage
The script accepts two required arguments:

1.  **Absolute Path to Repository:** 
* This is the path to the update site repository generated by your local Franca build.
* While the relative path inside the Franca project is franca/releng/org.franca.updatesite/target/repository, you must provide the absolute path (e.g., /home/user/franca/...).
2.  **Version:** 
* This is the specific version generated by the Franca build.
* **Note** This version includes a timestamp (e.g., 202512212242) and changes with every build.
* **How to find it** Check the filenames of the `.jar` files inside the repository path defined in step 1.

**Syntax:**
```bash
./build_with_local_franca.sh <ABSOLUTE_PATH> <VERSION>
```

**Example:**
```bash
./build_with_local_franca.sh /home/username/franca/releng/org.franca.updatesite/target/repository 0.13.2.202512212242
```
